
# Personal blog

A simple SPA build in Svelte with SvelteKit, styled using TailwindCSS.


## Pocketbase

To run this project, you will need to add the following environment variables to your .env file

`VITE_API_KEY`


Also checkout the `README.md` file in the folder **/pocketbase**.




## Run Locally

Clone the project

```bash
  git clone https://github.com/jejkob4/personal-blog
```

Go to the project directory

```bash
  cd personal-blog
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```


## Deployment

To build this project run

```bash
  npm run build
```
