
# Personal blog

A simple SPA build in Svelte with SvelteKit, styled using TailwindCSS.


## Pocketbase

To access your pocketbase api, you will need to change the variable 
`API_URL` in **personal-blog/src/lib/index.js**

I know I could've used an .env variable, im lazy..

Also checkout the `README.md` file in the folder **/pocketbase**.




## Run Locally

Clone the project

```bash
  git clone https://github.com/jejkob4/personal-blog
```

Go to the project directory

```bash
  cd personal-blog
```

Install dependencies

```bash
  npm install
```

Start the server

```bash
  npm run dev
```


## Deployment

To build this project run

```bash
  npm run build
```
